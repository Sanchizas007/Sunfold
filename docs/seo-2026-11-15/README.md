## Выводы

- **Воронка (RevenueCat, за всё время):** 92 клиента, 0 триалов, 0 оплат, $0.
  Проблема в видимости, а не в цене или пейволе.
- **Позиции до 1.3:** по головным фразам («intermittent fasting», «fasting timer»,
  «fasting tracker», «16:8») в топ-200 Sunfold нет; есть только в хвостах
  («autophagy» — 183 в US, 84 в GB; «фазы голодания» it — 4).
- **Слова выбраны по подсказкам:** «keto» (73 подсказки в US) вместо «ketosis» (0);
  английские слова добавлены в поля ключей неанглийских витрин, потому что там
  вводят «intermittent fasting widget».
- **Цены конкурентов (US):** месяц $6.99–$16.99; разовую покупку продают
  Fasty и ещё один простой трекер («Pro: Unlimited Access») по $49.99, а у «IF: 16:8»
  она от $4.99 до $19.99. У Sunfold: месяц $2.99, год $29.99, разовая
  $79.99. **Применено 15.11 по команде владельца:** месячная $2.99→$4.99 (с 17.11,
  действующим подписчикам остаётся $2.99), разовая $79.99→$49.99 (сразу). Годовая $29.99 как была.
  Читать результат: `/v1/subscriptions/{id}/prices`, у разовой — расписание цен через `/v2`.

## Как замерять через неделю

Те же 48 фраз тем же способом (iTunes Search API по витрине + ранг в выдаче) и
сравнить с `baseline-2026-11-15.json`. Ждать сдвига только после того, как 1.3
выйдет из ревью и Apple переиндексирует метаданные (обычно 1–3 дня после выпуска).
