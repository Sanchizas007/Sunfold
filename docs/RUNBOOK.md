# Runbook: подключение покупок

Два раздела. **Первый** можно делать прямо сейчас, без единого аккаунта.
**Второй** — после оплаты Apple Developer, по порядку сверху вниз; порядок важен,
потому что каждый следующий шаг требует идентификаторов из предыдущего.

---

## A. Проверить покупки сегодня, без аккаунтов

В проекте лежит `Config/Sunfold.storekit` — конфигурация StoreKit с теми же тремя
продуктами, что будут в проде. Схема `Sunfold` уже на неё настроена.

⚠️ Конфигурация работает **только при запуске из Xcode** (`Cmd+R`). Через
`simctl` из терминала она не подхватывается — это ограничение Xcode, не проекта.
Поэтому этот прогон делаете вы, а не я.

### Сценарий на 5 минут

1. Открыть `Sunfold.xcodeproj`, выбрать симулятор, **Cmd+R**.
2. Пройти онбординг. На пейволе (значок «7 дн» справа сверху) должно быть
   написано «Локальная тестовая сборка… Деньги не списываются» и показаны три
   плана с ценами $2.99 / $14.99 / $34.99.
3. Купить годовой. Появится системный диалог симулятора — подтвердить.
4. Проверить, что бейдж сменился на **Pro**, а в настройках — «Sunfold Pro активен».
5. **Debug → StoreKit → Manage Transactions** в Xcode: там видна транзакция.
   Удалить её и убедиться, что приложение вернулось к бесплатному тарифу.

### Что именно проверять

- [ ] Три плана с правильными ценами, годовой выбран по умолчанию и показывает
      «Выгода 58%» и цену за месяц
- [ ] Покупка проходит, бейдж становится Pro, пейвол закрывается
- [ ] Гейтинг снят: в выборе графика пропали замки, в истории исчезла карточка
      «Показаны последние 7 дней», появились диаграммы
- [ ] **Restore** на чистой установке возвращает Pro
- [ ] Отмена покупки в системном диалоге не показывает ошибку
- [ ] После удаления транзакции доступ снова ограничен

Отдельно проверьте **истечение семидневного периода**: удалить приложение,
поставить заново, затем в `Debug → Simulate → …` перевести часы вперёд, либо
проще — временно поменять `Entitlements.fullAccessDays` на `0` и запустить.
Пейвол должен смениться с «Сохраните доступ» на обычный, а бесплатный тариф —
оставить 16:8 и неделю истории.

## B. После оплаты Apple Developer

### 1. Портал разработчика

- [ ] **Identifiers → App IDs**: создать `app.sunfold`, включить **App Groups**
- [ ] Создать `app.sunfold.widgets`, включить **App Groups**
- [ ] **Identifiers → App Groups**: создать `group.app.sunfold`
- [ ] Вернуться в оба App ID и привязать к ним эту группу

> Больше ничего не включать. Push, HealthKit, Sign in with Apple приложению не
> нужны, а каждая лишняя capability — это вопрос на ревью.

### 2. Xcode

- [ ] Оба таргета → **Signing & Capabilities** → **Team**: ваша команда
- [ ] Убедиться, что App Groups подхватилась и галочка у `group.app.sunfold` стоит

### 3. App Store Connect: приложение

- [ ] **My Apps → +** → New App, bundle ID `app.sunfold`, язык по умолчанию English
- [ ] **Зарезервировать имя Sunfold сразу** — имя занимается в момент создания
      приложения, и это единственная надёжная проверка, что оно свободно

### 4. App Store Connect: покупки

Идентификаторы должны совпадать с `StoreIDs` в `Sunfold/Services/Purchases.swift`
символ в символ, иначе продукты просто не загрузятся.

- [ ] **Subscriptions → создать группу** с названием `Sunfold Pro`
- [ ] В группе: `app.sunfold.pro.monthly`, 1 месяц, $2.99
- [ ] В группе: `app.sunfold.pro.yearly`, 1 год, $14.99
- [ ] **In-App Purchases → Non-Consumable**: `app.sunfold.pro.lifetime`, $34.99
- [ ] Для каждого — локализованные название и описание на en/uk/ru
- [ ] Заполнить **Paid Apps Agreement** и банковские данные. Без подписанного
      соглашения продукты не выйдут из статуса «Missing Metadata» и **не
      загрузятся в приложении**. Это самая частая причина «покупки не работают».

### 5. RevenueCat

- [ ] Создать проект, добавить приложение iOS с bundle ID `app.sunfold`
- [ ] **App Store Connect API key** загрузить в RevenueCat (иначе не будет
      валидации и статусы подписок не поедут)
- [ ] **Entitlements** → создать с идентификатором ровно `pro`
- [ ] **Products** → добавить три продукта по тем же ID
- [ ] Привязать все три продукта к entitlement `pro`
- [ ] **Offerings** → создать `default`, сделать current, добавить три пакета
- [ ] Скопировать **публичный** ключ (`appl_…`) из **API keys**

### 6. Ключ в проект

Открыть `Config/Sunfold-Info.plist`, вставить ключ:

```xml
<key>RCPublicAPIKey</key>
<string>appl_ВАШ_КЛЮЧ</string>
```

Ключ публикуемый, в бинарнике лежать безопасно — это не секрет.

После этого приложение само переключится на RevenueCat: плашка «Локальная
тестовая сборка» с пейвола исчезнет.

### 7. Проверка в песочнице

- [ ] **App Store Connect → Users and Access → Sandbox Testers**: создать тестера
      (почта, которой ещё нет в Apple ID)
- [ ] На устройстве: **Настройки → Developer → Sandbox Apple Account** — войти
- [ ] Собрать на устройство, купить годовой — деньги не списываются
- [ ] Проверить, что покупка появилась в RevenueCat → **Customers**
- [ ] Проверить **Restore** после переустановки
- [ ] В песочнице год сжимается до часа, месяц до 5 минут — можно посмотреть,
      что происходит после истечения

## Если покупки не загружаются

По убыванию частоты:

1. **Paid Apps Agreement не подписан** или банковские данные не заполнены
2. Продукты в статусе «Missing Metadata» — не хватает скриншота или описания
3. ID продукта в App Store Connect не совпадает с `StoreIDs`
4. Прошло меньше нескольких часов с создания продуктов — они не сразу доступны
5. Offering в RevenueCat не помечен **current**
6. Сборка запущена не под тем bundle ID
