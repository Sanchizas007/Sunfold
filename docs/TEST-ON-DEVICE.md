# Как поставить Sunfold на свой iPhone

Коротко: **скачать файл и установить нельзя**. В iOS нет аналога APK. Приложение
попадает на телефон только четырьмя путями: из Xcode по кабелю, через TestFlight,
из App Store или через корпоративный MDM. Ниже два реальных варианта.

---

## Вариант A — бесплатно, из Xcode по кабелю

Работает на обычном Apple ID, платить $99 не нужно. Подходит, чтобы пощупать
приложение сегодня.

**Есть один подвох.** Бесплатный аккаунт не поддерживает **App Groups**, а Sunfold
через них делится данными с виджетом. Поэтому для бесплатной сборки capability
надо снять, и тогда:

- приложение работает полностью: таймер, фазы, история, вес, пейвол, уведомления,
  Live Activity в Dynamic Island;
- **виджет на домашнем экране будет пустым** («Нажмите, чтобы начать») — он не
  увидит данные приложения.

Код к этому готов: без App Group хранилище само падает на локальное, приложение не
падает и ничего не теряет.

### Шаги

1. Подключите iPhone кабелем, на телефоне нажмите **Доверять**.
2. Откройте `Sunfold.xcodeproj`.
3. **Xcode → Settings → Accounts → «+» → Apple ID** — войдите своим Apple ID.
4. Выберите таргет **Sunfold** → вкладка **Signing & Capabilities**:
   - **Team** → ваш `(Personal Team)`
   - в блоке **App Groups** нажмите иконку корзины — удалите capability
   - **Bundle Identifier** — если Xcode пожалуется, что занят, поменяйте на
     свой, например `com.вашафамилия.sunfold`
5. То же самое для таргета **SunfoldWidgets**: Team, удалить App Groups, и bundle
   ID должен начинаться с bundle ID приложения плюс суффикс, например
   `com.вашафамилия.sunfold.widgets`.
6. Вверху Xcode выберите свой iPhone вместо симулятора и нажмите **▶ Run**.
7. Первый запуск телефон заблокирует. Зайдите на iPhone в
   **Настройки → Основные → VPN и управление устройством** → ваш Apple ID →
   **Доверять**. Запустите ещё раз.

### Ограничения бесплатного аккаунта

- Сборка живёт **7 дней**, потом приложение перестаёт открываться — просто
  запустите Run из Xcode заново.
- Одновременно не больше 3 приложений с бесплатной подписью.
- Не больше 10 новых App ID в неделю (Sunfold занимает два: приложение и виджет).

## Вариант B — $99, TestFlight (то, что вам нужно на самом деле)

После оплаты Apple Developer Program появляется TestFlight: **приложение ставится
по ссылке, без кабеля и без Xcode**, на любой ваш iPhone и iPhone тестировщиков.

- работает всё, включая App Groups и виджеты;
- сборка живёт 90 дней;
- внутреннее тестирование (до 100 человек) **не проходит ревью** — билд доступен
  через несколько минут после загрузки;
- внешнее тестирование (до 10 000 человек) проходит облегчённое ревью.

### Шаги

1. Оплатить Apple Developer Program, дождаться активации (обычно сутки).
2. Зарегистрировать в портале App ID `app.sunfold` и `app.sunfold.widgets`,
   создать App Group `group.app.sunfold` и привязать к обоим — см.
   [APP-STORE.md](APP-STORE.md), раздел 2.
3. В Xcode проставить **Team** в обоих таргетах.
4. Создать приложение в App Store Connect с bundle ID `app.sunfold`.
5. В Xcode: **Product → Destination → Any iOS Device**, затем
   **Product → Archive**.
6. В открывшемся Organizer: **Distribute App → App Store Connect → Upload**.
7. Через 10–30 минут билд появится в App Store Connect → TestFlight. Добавьте
   себя во внутренние тестировщики, поставьте TestFlight из App Store и
   установите Sunfold оттуда.

---

## Что выбрать

Если хотите просто посмотреть, как оно на телефоне — **вариант A**, 15 минут.

Если собираетесь публиковаться, $99 всё равно понадобятся, и **вариант B** сразу
даёт нормальный цикл: загрузил билд — поставил по ссылке — проверил виджеты и
покупки в песочнице. Возиться с ручным снятием App Groups тогда не нужно.
